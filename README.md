# 🐍 Python Practice Journey

Welcome to my Python practice repository.

This repository is a collection of the programs, exercises, and mini projects I build while learning Python. Instead of keeping my practice hidden on my computer, I decided to document my progress publicly so I can look back at how far I have come and hopefully encourage other beginners who are on the same journey.

Every file in this repository represents a concept I practiced, a problem I solved, or something new I learned. Some programs are very simple, while others will gradually become more challenging as my skills grow.

## Why I Created This Repository

Learning programming is not about writing perfect code from day one. It is about consistency, curiosity, and continuous improvement.

I created this repository to:

- Practice Python every day
- Build strong programming fundamentals
- Track my learning progress over time
- Improve my problem solving skills
- Create a habit of using Git and GitHub regularly
- Build a portfolio that reflects my learning journey

Rather than deleting old beginner code, I prefer to keep it here because it reminds me where I started.
